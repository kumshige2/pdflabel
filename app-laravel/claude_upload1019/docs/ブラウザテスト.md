# お問い合わせ一覧アプリ ブラウザテストケース一覧

対象機能: お問い合わせフォーム（公開側）／お問い合わせ管理（管理側）
参照: [お問い合わせフォーム_仕様書.md](./お問い合わせフォーム_仕様書.md)

本ドキュメントは `テストケース.md`（サンプル）の構成を踏襲しつつ、実際の実装内容（ルーティング・バリデーション・画面表示）に合わせて項目を作成したものです。サンプルにあった「検索・フィルタ」「ページネーション2ページ目遷移」等、本アプリで未実装の機能に関する項目は対象外としています。

## 0. 前提

- お問い合わせフォーム（`/contact`系）・管理ページ（`/admin/contacts`系）は、いずれも既存アプリの`auth`ミドルウェア配下にあり、**ログインが必須**（サンプルと異なり、お問い合わせフォーム自体もログインしないと使えない社内向け機能）
- 管理ページ専用の`/admin/login`は存在しない。既存アプリの通常ログインと共通
- バリデーションエラーメッセージは、本アプリが日本語化（`lang/ja/validation.php`等）されていないため、**英語表記**になる（例:「The name field is required.」）
